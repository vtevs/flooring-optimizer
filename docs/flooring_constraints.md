# 木地板铺装约束定义

日期：2026-06-16

本文记录当前项目采用的铺装、切割、榫槽、拼缝、伸缩缝和不可铺装区域约束。后续优化、校验、审计报告应以本文为准。

## 坐标与单位

- 坐标单位为 `mm`。
- 平面坐标以房间左下角为 `(0,0)`。
- `x` 轴向右，`y` 轴向上。
- 用户描述中，“长”为 `X` 方向，“宽”为 `Y` 方向。
- SVG 渲染可以使用屏幕坐标翻转，但几何计算必须保持上述数学坐标。

## 单片地板规格

当前项目地板规格为：

```text
长度: 610mm
宽度: 92mm
厚度: 18mm
```

铺装几何中，地板被视为平面矩形；厚度只用于约束是否允许翻面。

## 材料类型

材料通过顶层配置选择：

```yaml
material:
  type: wood  # wood | tile
```

默认值为 `wood`。

`wood` 表示木地板：

- 内部邻边必须通过公母榫 `T/G` 对接证明；
- 内部邻边不得出现切割边；
- 余料复用可以受保留边/切割边约束影响。

`tile` 表示瓷砖：

- 不执行公母榫逐边证明；
- 内部邻边允许切割边；
- 切割余料按尺寸复用，不按公榫/母榫边型筛选。

无论材料类型如何，切割面积、锯缝、覆盖范围、超出房间等校验仍然执行。

## 供应商 A/B 源板定义

配置 `board.stock_class_policy: supplier-ab-vertical` 时，源板以板面朝上、
长度方向竖直、顶/底为短边作为 `0°` 基准：

| 源板类型 | 顶短边 | 右长边 | 底短边 | 左长边 |
| --- | --- | --- | --- | --- |
| A | 公榫 T | 母榫 G | 母榫 G | 公榫 T |
| B | 公榫 T | 公榫 T | 母榫 G | 母榫 G |

A、B 是两种独立库存类型。A 板或 B 板都允许在俯视平面内旋转
`0/90/180/270°`，但旋转不会改变其库存类型；尤其 `90/270°` 会交换铺装矩形
的长宽方向，不能据此把 A 板等同于 B 板。

## 安装方向约束

- 不允许沿厚度方向翻面使用，即 18mm 的顶部和底部不能互换。
- 允许在俯视平面内旋转使用。
- 每块板在求解中允许选择以下四种平面旋转状态：
  - `0°`
  - `90°`
  - `180°`
  - `270°`

旋转只改变四边在平面坐标中的对应方向，不改变板面朝上这一事实。求解结果必须
同时记录源板类型、源板旋转角和切割片在源板上的坐标，校验器不允许事后为同一块
板重新选择一个更容易通过的方向。

## 邻边拼接定义

内部邻边是指两块地板在平面中：

- 边互相平行；
- 边之间的距离约等于 `board_gap`；
- 两条边在投影方向上有有效重叠；
- 该边不是房间边界、柜子边界或其它不可铺装区域边界。

内部邻边必须满足：

```text
TONGUE ↔ GROOVE
GROOVE ↔ TONGUE
```

不允许：

```text
TONGUE ↔ TONGUE
GROOVE ↔ GROOVE
CUT    ↔ 任意内部邻边
```

其中 `CUT` 表示切割面。切割面只能出现在房间边界、柜子边界、L 形缺口边界等非内部拼接边。

## 公母榫严格证明

校验器对每个房间执行以下证明：

1. 从铺装结果中提取每块板的实际使用多边形。
2. 根据 `board_gap` 识别所有内部邻边。
3. 若内部邻边包含切割边，则立即判定失败。
4. 为每块铺装片枚举 A/B 类型、四种源板旋转及可实现的源板切割位置。
5. 同一源板切出的板片必须具有相同 A/B 类型，并共享同一张不重叠且满足锯缝的
   源板坐标图。
6. 原厂边继承旋转后的榫槽属性；离开源板外轮廓的边一律为 `CUT`。
7. 用约束求解证明所有内部邻边可以同时满足 `T/G` 对接，并将求解结果固化到输出。
8. 校验阶段复算固化的类型、旋转、切割继承和全部内部邻边，不重新求解替代状态。

若求解成功，则认为该房间的公母榫对接被严格证明。

## 板间拼缝

当前三 L 拼现实铺装使用：

```text
board_gap = 0mm
```

`board_gap` 进入三 L 拼坐标步距：

```text
S = board_width + board_gap
```

板间拼缝不消耗木材，但会占据可铺区域面积。因此审计报告同时给出两种损耗口径：

- 显示口径：`可铺区域面积 / 采购整板面积`
- 木材口径：`实际木材覆盖面积 / 采购整板面积`

## 伸缩缝

当前伸缩缝为：

```text
expansion_gap = 18mm
```

伸缩缝作用于所有需要预留的边界：

- 房间墙边；
- L 形房间内角和外边；
- polygon 房间轮廓边；
- 柜子、衣柜、固定家具等不可铺装区域边缘。

几何计算顺序为：

```text
房间原始轮廓 - 不可铺装区域 = 净房间区域
净房间区域 buffer(-expansion_gap) = 最终可排样区域
```

踢脚线宽度当前不扣减可铺区域；代码注释假定踢脚线压在地板上方。

## 不可铺装区域

不可铺装区域包括柜子、衣柜、固定家具等。它们在配置中通过 `obstacles` 描述。

矩形障碍物示例：

```yaml
obstacles:
  - name: wardrobe
    type: rectangle
    x: 0
    y: 2862
    width: 1830
    length: 600
```

多边形障碍物示例：

```yaml
obstacles:
  - name: custom-cabinet
    type: polygon
    points:
      - [1000, 500]
      - [1600, 500]
      - [1700, 900]
      - [1200, 1100]
```

渲染规则：

- 障碍物区域以矩形或多边形显示；
- 内部画两条对角线形成 `X`；
- 地板不得铺入障碍物区域，也不得铺入障碍物边缘预留的伸缩缝区域。

## 房间轮廓

当前支持以下房间类型：

### rectangle

```yaml
type: rectangle
width: 2856
length: 3462
```

### l-shaped

表示外接矩形减去一个角部缺口：

```yaml
type: l-shaped
width: 3600
length: 4200
notch:
  position: top-left
  width: 1200
  depth: 900
```

### polygon

用于描述凸出、凹入或更一般的房间轮廓：

```yaml
type: polygon
points:
  - [0, 0]
  - [3254, 0]
  - [3254, 3460]
  - [1063, 3460]
  - [1063, 5447]
  - [0, 5447]
```

点按顺时针或逆时针给出均可，但不能自交。

## 切割与锯缝

当前锯缝为：

```text
kerf = 1.5mm
```

切割约束：

- 长度切割产生长度尾料，尾料可复用；
- 宽度切割产生宽度尾料，满足可用条件时可复用；
- 组合切割同时记录长度废料和宽度废料；
- A/B 模式下，每块切割片记录其在 `92 × 610mm` 源板坐标系中的分配矩形；
- 房间拐角或柜体边界产生缺角时，还必须记录最终真实多边形轮廓，不能用外接矩形代替；缺角新增边均为 `CUT`；
- 同源切割片不得重叠、不得越界，投影相交时片间距离不得小于 `kerf`；
- 点击 HTML 中的切割板时，必须按绝对坐标和真实多边形轮廓绘制同源切割图并显示校验结论；
- 非 A/B 模式下，每次切割仍按使用片、显式废料和锯缝面积核对原料面积；
- 锯缝不单独计入采购面积，而是通过可复用尺寸和废料面积影响最终用板数。

## 角落整板起铺规则

可通过配置启用：

```yaml
installation:
  require_full_board_at_room_corner: true
  require_full_board_at_room_bottom_left: false
```

启用后，每个房间在完成障碍物扣除和伸缩缝内缩后，至少需要有一个真实可铺装区域角落被一块未切割整板覆盖。角落不固定为某一方向，优化器会在满足该约束的候选方案中继续选择最低损耗方案。

若 `require_full_board_at_room_bottom_left: true`，则规则进一步收紧为：每个房间都固定从最终可铺装区域左下角 `(minx, miny)` 起铺，使左下角第一块板为整板。该模式不再自由搜索每个房间的起铺 offset，但仍会优化房间顺序和尾料复用。

对于 L 形或 polygon 房间，外包框中不属于房间轮廓的虚角不会参与判断。

## 当前审计输出

### 优化结论口径

当前 `supplier-ab-vertical` 求解会比较原同源组合的联合约束解，以及把源片拆开后
按物理兼容图执行全局最大配对的重组解，并按 `1:1` 采购数、实际源板数选择较优者。
指定 `full_board_start_corner` 的房间，其铺装偏移由该角点规则固定。

当前输出属于已通过严格物理校验的最好已找到方案；求解器尚未枚举所有可行的
A/B/旋转赋值组合，因此不能把损耗数字表述为带数学下界证书的全局最优值。

审计报告应包含：

- 综合用板数；
- 显示口径损耗；
- 木材口径损耗；
- 分房间可铺面积、木材覆盖面积、拼缝面积；
- 公母榫逐边校验结果；
- A/B 实际消耗数及按 `A:B = 1:1` 配板的采购数；
- 同源切割坐标、锯缝与铺装覆盖校验结果。
